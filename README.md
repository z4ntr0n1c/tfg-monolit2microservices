Paraules clau: Microservices, Cloud, Arquitectura Monolítica, API, Kubernetes, Docker, API, Apache Kafka, Pipelines CI/CD, DevOps, GitOps 

Aquest treball explora la migració d'una aplicació monolítica clàssica cap a una arquitectura basada en microserveis, amb l'objectiu d'analitzar els beneficis i reptes d'aquesta transició. Aprofitant l'experiència adquirida en un projecte real, el context d'aplicació inclou una organització que busca modernitzar la seva infraestructura per millorar la gestió, la flexibilitat i l'eficiència energètica. 
La metodologia combina pràctiques modernes com DevOps i GitOps per facilitar la transició, amb una anàlisi detallada dels tres components principals de l'aplicació: Front-End, Back-End i base de dades. El projecte es divideix en fases, des del disseny i la planificació fins a la implementació i validació. S'inclouen eines com contenidors, plataformes de Cloud Computing i tècniques d'escalabilitat dinàmica. 
Els resultats esperats se centren en l'obtenció d'una arquitectura més robusta, flexible i econòmica, amb una optimització significativa dels recursos tecnològics i una reducció del consum energètic. També es preveu una millora en la capacitat de desplegament i manteniment de funcionalitats. 
Les conclusions apunten a com l'arquitectura de microserveis pot millorar la sostenibilitat tecnològica i ambiental, alhora que es redueixen costos operatius. Aquest treball no només documenta el procés de migració, sinó que també busca demostrar el valor d'aquesta transformació per a empreses que aspiren a mantenir-se competitives en un entorn tecnològic en constant evolució. 
-----
This project explores the migration of a traditional monolithic application to a microservices-based architecture, focusing on analyzing the benefits and challenges of this transformation. Leveraging real-world experience from a current project, the application context involves an organization seeking to modernize its infrastructure to improve management, flexibility, and energy efficiency. 
The methodology incorporates modern practices such as DevOps and GitOps to streamline the transition, along with a detailed analysis of the three main application components: Front-End, Back-End, and database. The project is structured into phases, from design and planning to implementation and validation, employing tools like containers, cloud computing platforms, and dynamic scalability techniques. 
Expected results include a more robust, flexible, and cost-effective architecture, significantly optimized technological resources, and reduced energy consumption. Additionally, enhanced deployment and maintenance capabilities for application functionalities are anticipated. 
The conclusions underline how microservices architecture can enhance technological and environmental sustainability while reducing operational costs. This project not only documents the migration process but also aims to demonstrate the value of such a transformation for businesses striving to remain competitive in an ever-evolving technological landscape.
